# Сервис предзаказа билетов на футбольные матчи

Кликабельный прототип веб-сервиса для предзаказа билетов на футбольные матчи.

## 🚀 Демо

Проект готов к размещению на GitHub Pages. После загрузки файлов в репозиторий, активируйте GitHub Pages в настройках репозитория.

## 📋 Функциональность (Must Have)

### Неавторизованный пользователь
- ✅ Просмотр списка доступных матчей
- ✅ Просмотр детальной информации о матче
- ✅ Регистрация в системе
- ✅ Оформление предзаказа (с перенаправлением на авторизацию)

### Авторизованный пользователь
- ✅ Ознакомление с условиями оферты
- ✅ Настройка параметров предзаказа (сектор, ряд, места, лимит цены)
- ✅ Привязка платежных средств (карты)
- ✅ Отмена предзаказа до старта продаж
- ✅ Получение уведомлений о выполнении предзаказа
- ✅ Получение билета на email (имитация)

### Организатор
- ✅ Учет требования Fan ID для определенных матчей

## 🚀 Развертывание на GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Загрузите все файлы проекта в репозиторий
3. Перейдите в Settings → Pages
4. В разделе "Source" выберите ветку `main` и папку `/ (root)`
5. Нажмите "Save"
6. Через несколько минут сайт будет доступен по адресу: `https://[ваш-username].github.io/[название-репозитория]/html/`

**Примечание**: Главная страница находится по пути `/html/index.html`

## 💡 Особенности реализации

- **Хранение данных**: Все данные хранятся в cookies браузера (пользователи, предзаказы, карты)
- **Имитация backend**: Вся бизнес-логика реализована на frontend
- **Валидация**: Реализована валидация форм (email, пароль, карты)
- **Адаптивный дизайн**: Интерфейс адаптирован для мобильных устройств
- **Футбольная тематика**: Минималистичный дизайн с футбольными акцентами
